Add items to a module’s menu¶

Right-clicking a module opens its context menu: Rack’s own items, then any your module widget adds. This guide adds labels, actions, check marks, submenus and settings, with Rack’s menu helpers.

Status: Linux x86_64, Rack Free 2.6.6, tested in Rack (examples/menus, whose module uses every helper below).

Override append_context_menu¶

Rack calls your module widget’s append_context_menu(menu) each time the menu opens, after adding its own items. Add yours to menu:

examples/menus/pythonpath/rackpymenus/switchboard.py · from an example plugin tested in Rack¶
class SwitchboardWidget(app.ModuleWidget):
    """The module's panel. Rack passes the module, or None for its browser's preview."""

    def __init__(self, module: Module | None) -> None:
        super().__init__()
        self.set_module(module)
        self.set_panel(raw.create_panel(str(assets.plugin("res/Switchboard.svg"))))
        right, bottom = self.box.size.x - 2 * app.RACK_GRID_WIDTH, app.RACK_GRID_HEIGHT - app.RACK_GRID_WIDTH
        self.add_child(raw.create_widget(cl.ScrewSilver, Vec(app.RACK_GRID_WIDTH, 0)))
        self.add_child(raw.create_widget(cl.ScrewSilver, Vec(right, bottom)))
        self.add_output(raw.create_output_centered(cl.PJ301MPort, mm2px(Vec(10.16, 108.0)), module, Output.PITCH))
        self.add_child(
            raw.create_light_centered(cl.SmallLight[cl.RedLight], mm2px(Vec(10.16, 90.0)), module, Light.MUTED)
        )

    def append_context_menu(self, menu: ui.Menu | HostWidget) -> None:
        board = Switchboard.of(self.module)
        if board is None:  # no module, as in the browser: nothing to choose
            return
        menu.add_child(ui.MenuSeparator())
        menu.add_child(raw.create_menu_label("Pitch"))
        top = len(OCTAVES) * 12 - 1
        at = board.octave * 12 + board.note
        menu.add_child(raw.create_menu_item("Up a semitone", "", lambda: board.nudge(1), disabled=at >= top))
        menu.add_child(raw.create_menu_item("Down a semitone", "", lambda: board.nudge(-1), disabled=at <= 0))
        menu.add_child(
            raw.create_check_menu_item(
                "Middle C", "", lambda: (board.octave, board.note) == (2, 0), lambda: board.choose(2, 0)
            )
        )

        def fill_presets(submenu: ui.Menu) -> None:  # runs when the submenu opens
            for name, (octave, note) in PRESETS.items():
                submenu.add_child(raw.create_menu_item(name, "", partial(board.choose, octave, note)))

        menu.add_child(raw.create_submenu_item("Presets", "", fill_presets))
        menu.add_child(
            raw.create_index_submenu_item(
                "Octave", list(OCTAVES), lambda: board.octave, lambda octave: board.choose(octave, board.note)
            )
        )
        menu.add_child(raw.create_index_ptr_submenu_item("Note", list(NOTES), Choice(board, "note")))
        menu.add_child(ui.MenuSeparator())

        def set_muted(muted: bool) -> None:
            board.muted = muted
            board.send()

        menu.add_child(raw.create_bool_menu_item("Muted", "", lambda: board.muted, set_muted))
        menu.add_child(raw.create_bool_ptr_menu_item("Inverted", "", Choice(board, "inverted")))

The helpers live in rackpy.raw and match Rack’s C++ createMenuItem family:

Helper

Makes

ui.MenuSeparator()

a line between groups

create_menu_label(text)

a heading that does nothing

create_menu_item(text, right_text="", action=None, disabled=False)

a plain or action item; disabled=True disables either kind

create_check_menu_item(text, right_text, checked, action)

an item with a check mark while checked() is true

create_bool_menu_item(text, right_text, getter, setter)

a checkable setting through a getter and a setter

create_bool_ptr_menu_item(text, right_text, ptr)

the same, through ptr: any object with a value attribute

create_submenu_item(text, right_text, create_menu)

a submenu that create_menu(submenu) fills when it opens

create_index_submenu_item(text, labels, getter, setter)

a submenu that chooses one of labels by index

create_index_ptr_submenu_item(text, labels, ptr)

the same, through an object with a value

Where C++ takes a pointer to a field, RackPy takes an object with a value attribute: the example’s Choice stores the value in the module’s state and hands the kernel the new voltage when it changes. The ui reference gives each helper’s exact signature.

What to keep in mind¶

  • The browser’s preview has no module. Rack builds your widget with None for its module browser. Add no module items then, as the example’s first line does.

  • Menu callbacks run on Rack’s main thread, when the user chooses an item. They may change the module’s state and Python objects freely; to change what the audio does, set a kernel control (kernel.set(...)), which reaches the engine at the next sample.

  • An item can outlive its module. If the module is deleted while its menu is open, a callback still runs when chosen. Check module.alive before using the module, as the example’s send() does. RackPy contains any error a callback raises.

  • Save what the menu sets. Settings chosen from the menu are module state: save them in to_json and restore them in from_json (state). The example does, and Initialize resets them.
