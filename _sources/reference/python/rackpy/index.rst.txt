rackpy
======

.. py:module:: rackpy

.. autoapi-nested-parse::

   RackPy: Python for VCV Rack plugins.

   Native bindings require the RackPy host running inside
   VCV Rack; the API and cross-platform coverage remain incomplete. See
   https://github.com/feoh/RackPy for the coverage contract.
