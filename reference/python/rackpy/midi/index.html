rackpy.midi¶

MIDI, Pythonically, over rackpy.raw.midi. Inside Rack’s live UI only.

Everything here is synchronous and runs on Rack’s main thread. A message arrives at an Input subclass’s on_message on the UI thread, queued (never on the MIDI driver’s thread); an InputQueue keeps messages until you pop them. The raw layer’s rules apply unchanged (see the MIDI reference page); nothing here has native semantics of its own.
