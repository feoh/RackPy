rackpy.simd¶

Rack’s 4-lane SIMD vectors and the math on them, as one tidy import.

float_4 and int32_4 hold Rack’s own C++ vectors (rack::simd, also available as rackpy.raw.simd), and every operator and function runs Rack’s C++ code, so results match Rack’s lane for lane. Comparisons return masks, not bools. Each function also takes plain floats, as Rack’s do, so code written once works for a float and for a float_4. Available inside Rack only.

Python calls cost far more than the four lanes they compute: use these to configure, test and explore Rack’s SIMD semantics, not for per-sample audio, which belongs in a native kernel (see the DSP how-to).
