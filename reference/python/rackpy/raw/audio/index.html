rackpy.raw.audio¶

rack::audio: Rack’s audio drivers and devices, and Python-owned audio ports.

Classes¶

Driver

One of Rack's audio drivers, by its ID.

PortView

A port Python did not make (a module's), listed by a device's subscribers; read-only.

ProcessMutexGuard

RAII guard for a device's process mutex; use and release on the acquiring UI thread.

ProcessMutex

Lifetime-checked view of Rack's audio device process mutex.

Device

An audio device, through the Python port that holds it.

Port

Rack's audio port. Python owns it; main thread, in Rack's live UI context.

PythonDevice

An audio device of a PythonDriver: Rack's ports subscribe to it, and Python drives its stream.

PythonDriver

An audio driver Python configures; add_driver gives it to Rack.
