# Provenance: envelope

## Behavioral reference

The attack/decay, end-of-cycle and optional looping feature set was identified
from Amplified Futures by Daniel Boles at the pinned repository commit
[`06794bca8ccbc3b413b929713017a252783dce51`](https://github.com/dboles99/amplified-futures-vcv/tree/06794bca8ccbc3b413b929713017a252783dce51),
not from a moving branch. This example was independently implemented from the
RackPy API and Rack 2.6.6 public headers. No upstream source code was copied or
adapted; no endorsement is implied. Its behavior and interface intentionally
omit upstream branding and distinctive presentation.

The selected upstream source files are MIT-licensed; if any upstream code is
ever copied into this example, retain Daniel Boles' copyright, the complete MIT
permission notice and disclaimer in the source and binary notices. This version
contains no such copied code, so its own implementation is GPL-3.0-or-later.
The upstream `res/insects/` audio is excluded entirely (it is separately
licensed CC BY 4.0 and is unnecessary here).

## Original assets

`res/Envelope.svg` is original RackPy panel artwork, not derived from Rack,
Fundamental, or Amplified Futures. Rack component-library knobs, switch, jacks
and screws are loaded from the user's Rack installation at runtime.
