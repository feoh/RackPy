# Provenance: Feedback Governor

The module's feature set is behaviorally inspired by **Feedback Governor** by
Daniel Boles in Amplified Futures. Reference repository:
<https://github.com/dboles99/amplified-futures-vcv>, pinned commit
`06794bca8ccbc3b413b929713017a252783dce51`; see its
[`FeedbackGovernor.cpp`](https://github.com/dboles99/amplified-futures-vcv/blob/06794bca8ccbc3b413b929713017a252783dce51/src/FeedbackGovernor.cpp)
and
[module notes](https://github.com/dboles99/amplified-futures-vcv/blob/06794bca8ccbc3b413b929713017a252783dce51/docs/modules/FeedbackGovernor.md).

This RackPy implementation is independent: no source, text, names beyond the
behavioral reference, artwork, panel layout, audio, fonts, or binaries were
copied. The native algorithm, RackPy facade, panel, and reference tests were
written for this example. Daniel Boles and Amplified Futures do not endorse,
sponsor, or maintain RackPy. The upstream project identifies its source as MIT;
this example does not incorporate upstream code and therefore does not claim
that its source or assets are covered by that separate MIT grant. No insect
audio is used.

## Original assets

`res/FeedbackGovernor.svg` is new RackPy artwork. The panel layout, typography,
and trace motif are original; Rack component-library controls are rendered by
Rack at runtime.
