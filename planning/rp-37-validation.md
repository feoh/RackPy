### The quickstart in a clean profile

The script at the end of this record: an empty `HOME`
(fresh uv, RackPy and Rack caches and an empty Rack user folder), a fresh
`git clone` of `rp37`, `PATH` limited to the tools the quickstart names (uv,
CMake, Ninja, GCC, git) and `/usr/bin`, then the quickstart's commands as
written, with Rack Free 2.6.6 started headless to create its user folder and
again to load the plugin. Every step succeeded; step 1 (download and build)
took 216 s, the whole run 230 s. Rack's log: `RackPy interpreter started`,
`Loaded plugin MyPlugin 2.0.0`, and at exit `Py_FinalizeEx returned 0`.

What it changed: the claim that no Python is needed was softened to what uv
does (it installs one only if the system has none), since `/usr/bin`, which
CMake needs, also holds a system Python. No other prerequisite was missing.

## The clean-profile script

```bash
#!/bin/bash
# RP-37: the quickstart in a clean profile: an empty HOME (fresh uv, RackPy and Rack caches), a fresh clone,
# only the tools the quickstart names on PATH, then its commands as written. Rack itself is the pinned
# Rack Free 2.6.6 already on this machine, started headless with the clean HOME's user folder.
set -euo pipefail
ROOT=/tmp/rp37-clean
rm -rf "$ROOT" && mkdir -p "$ROOT/home" "$ROOT/bin"
for t in uv cmake ninja gcc g++ git make; do ln -s "$(command -v $t)" "$ROOT/bin/$t" 2>/dev/null || true; done
export HOME="$ROOT/home" PATH="$ROOT/bin:/usr/bin:/bin"
unset UV_CACHE_DIR XDG_CACHE_HOME XDG_DATA_HOME XDG_CONFIG_HOME VIRTUAL_ENV PYTHONPATH
cd "$ROOT"
start=$(date +%s)
git clone -q --branch rp37 /home/feoh/src/personal/RackPy-rp37 rackpy
cd rackpy
echo "== step 1: build RackPy"
uv sync --frozen
bin/rackpy-dev build
rm -rf /tmp/rackpy-bundle-clean && bin/rackpy-dev bundle /tmp/rackpy-bundle-clean
echo "== step 1 took $(( $(date +%s) - start )) s"
echo "== step 2: create"
bin/rackpy-plugin create MyPlugin --license GPL-3.0-or-later --name "My Plugin" --author "Your Name"
echo "== step 3: add a module"
cp examples/oscillator/res/Oscillator.svg MyPlugin/res/MyModule.svg
bin/rackpy-plugin add-module MyModule --project MyPlugin --panel MyPlugin/res/MyModule.svg \
    --name "My Module" --description "My first module" --tags Oscillator
echo "== step 4: build into Rack"
RACK=/home/feoh/.cache/rackpy/sdk/host/extracted/lin-x64-69acf0c98d47db38/Rack2Free
(cd "$RACK" && (sleep 5; echo) | flock -w 1800 /tmp/rackpy-host-tests.lock timeout 60 env -u DISPLAY -u WAYLAND_DISPLAY ./Rack -h > /dev/null 2>&1 || true)
ls -d ~/.local/share/Rack2/plugins-lin-x64   # "Start it once, so that it creates its user folder"
bin/rackpy-plugin build MyPlugin --bundle /tmp/rackpy-bundle-clean/RackPy --dest ~/.local/share/Rack2/plugins-lin-x64
cd "$RACK" && (sleep 8; echo) | flock -w 1800 /tmp/rackpy-host-tests.lock timeout 60 env -u DISPLAY -u WAYLAND_DISPLAY ./Rack -h > /dev/null 2>&1 || true
grep -E "RackPy|Loaded plugin MyPlugin" ~/.local/share/Rack2/log.txt
echo "== total $(( $(date +%s) - start )) s"
```
